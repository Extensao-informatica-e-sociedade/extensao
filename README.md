# Extensão Conecta Turismo

Aplicação web desenvolvida com React, TypeScript e Vite para o projeto EmpreendeTech.

## Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router DOM
- Capacitor (mobile)

## Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar em modo desenvolvimento
npm run dev

# Build de produção
npm run build

# Preview do build
npm run preview
```

## Testes

```bash
npm run test
```
